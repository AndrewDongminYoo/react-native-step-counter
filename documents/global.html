createStepCountFilter()

Create a stateful filter for live step-count updates.

Native pedometer APIs can already include device/OS false positives, and the Android accelerometer fallback can also react to quick hand rotation. This helper rejects totals that exceed the session's measurement-time cadence budget and rebases later values so demonstrated impossible steps do not come back. It cannot detect false steps hidden by idle time earlier in the session. A newer startDate or backend change resets adjustments; stale events are ignored. Create a fresh filter when restarting with the same startDate and backend. Unavailable distance remains null. Distance correction cannot attribute increments across unavailable intervals; only observed adjacent increments are removed.

startStepCounterUpdate(start, callBack) → {EventSubscription}

Start to subscribe stepCounter updates. If native start throws synchronously, the new listener is removed and the error is rethrown. If stopping a previous session throws, its listener is removed and that error propagates before a replacement listener or native session is started.

iOS

Live updates exclude activity recorded before this call, even for a past start date. iOS queries the available history from start to the call time as a baseline, then subtracts it from steps, distance, and floors. Emitted startDate is that cutoff and endDate is the measurement time. Future origins clamp to the call time. Missing baseline/current optional metrics remain null; an unknown baseline stays null for the session. If the query fails, the first valid live sample becomes the baseline and its end date becomes the cutoff; that sample is not emitted. Zero-step, stale, or decreasing windows are ignored without lowering baselines. Native queryStepCounterDataBetweenDates instead returns the requested historical interval (limited to available Core Motion history) without live-session subtraction. It is not exposed by this TypeScript wrapper. CMPedometer.startUpdates replaces the deprecated CMStepCounter API.
